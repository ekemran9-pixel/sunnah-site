# সুন্নাহর পথে

নবী মুহাম্মাদ ﷺ-এর জীবনী, দৈনিক রুটিন, পারিবারিক আচরণ, সমস্যা সমাধান, যুদ্ধনীতি, উপদেশ, করণীয়-বর্জনীয় এবং দৈনিক সুন্নাহ ট্র্যাকার। প্রতিটি তথ্যের সাথে কুরআন ও হাদিসের সূত্র দেওয়া আছে।

- `index.html` — মূল পেজ
- `docs/index.html` — GitHub Pages-এর জন্য তৈরি পূর্ণ HTML (`./build.sh` চালিয়ে বানানো)
